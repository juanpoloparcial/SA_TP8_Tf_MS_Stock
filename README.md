Modelo TensorFlow.js - y = 2x + 6

Este proyecto es un sitio web simple que entrena un modelo de regresión lineal usando TensorFlow.js 
para aprender la relación y = 2x + 6. El modelo se entrena automáticamente al cargar la página y luego 
permite al usuario ingresar un valor para `x` y obtener la predicción de `y`.

Pasos para ejecutar el proyecto

Clona o descarga el repositorio:
  git clone ...

Seguir las instrucciones que nos da el programa para rellenar los campos y obtener la predicción.
